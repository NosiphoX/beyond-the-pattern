# Beyond the Pattern

An interactive research prototype about whether meaning depends on knowing a conscious person wrote something. Each round, a participant answers a question, then reads two anonymous answers side by side (one from a stored human, one freshly generated by an AI model), guesses which is AI, and only then sees the truth. A closing question asks them to reflect on what meaning depends on.

**Live prototype:** https://beyond-the-pattern.vercel.app

## How it works

- The participant's own answer is saved to a pool and never shown back to them. They compare a *different* stored human answer with a live AI answer, so the judgement is genuinely blind.
- The AI answer is generated live through the Gemini API from a serverless function (`api/generate.js`), so the API key never reaches the browser.
- After the guesses, a reveal screen shows which was which, and asks whether the participant suspected it and how it feels now.
- Seed human answers come from the HC3 corpus (Guo et al., 2023) and from friends and classmates who agreed to contribute anonymised answers.

## Run it locally

Requirements: Node.js 18 or later, a free Gemini API key, a free Vercel account.

1. `npm install`
2. Create a file called `.env` in the project root containing one line: `GEMINI_API_KEY=your-key-here`
3. `npx vercel login`, then `npm run dev:full`
4. Open the address it prints (usually http://localhost:3000). Do not use the plain `npm run dev` address, because it does not run the `/api` functions.

## Project structure

- `src/App.jsx` and `src/index.css`: the interface
- `api/`: serverless functions (`generate`, `questions`, `save-and-pick`, `save-results`)
- `data/pool.json`: questions and seed human answers

#   ## Data storage

   Answers and results are saved to an Upstash Redis database (via Vercel) when its credentials are present, and to local JSON files in `data/` otherwise. This means participants' answers join the comparison pool and their results are kept, on the deployed version as well as locally.

## Reference
